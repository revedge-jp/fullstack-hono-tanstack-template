# pr-create: PR の作成

このコマンドは、GitHub へ PR を作成します。

**重要: このコマンド実行中は、すべての応答を日本語で行ってください。**

## 実行内容

1. 現在のブランチが main 以外であればブランチを作成
2. コミットがなければ現在の変更を全てコミット
3. diff を取得し PR の概要欄を生成
4. PR を作成（gh コマンド）
5. PR の URL を `open` コマンドで開く

## 指示

- まず `git branch --show-current` で現在のブランチを確認してください
- main ブランチにいる場合は、新しいブランチを作成してください
- `git status` で未コミットの変更がないか確認してください
- 未コミットの変更がある場合は、コミットしてください（コミットメッセージは日本語で）
- `git diff origin/main...HEAD` で差分を取得してください
- 差分を基に PR のタイトルと概要を生成してください
- `git push origin HEAD` でリモートにプッシュしてください
- `gh pr create --draft --title "{PRタイトル}" --body "{PR概要}"` で PR を作成してください
- `gh pr view --web` または `open {PR URL}` で PR をブラウザで開いてください

---

実行: チャット入力で `/pr-create` を選択してください。
