# commit: 変更のコミット

このコマンドは、現在の変更をすべてコミットします（プッシュはしません）。

**重要: このコマンド実行中は、すべての応答を日本語で行ってください。**

## 実行内容

1. 現在の変更を全てコミット
2. コミットメッセージは日本語で行うこと

## 指示

- `git status` で変更内容を確認してください
- `git add .` で変更をステージングしてください
- コミットメッセージは日本語で、変更内容を簡潔に説明してください
  - 例) `feat: ユーザー API エンドポイントを追加`, `fix: ログインエラーを修正`
- `git commit -m "{コミットメッセージ}"` でコミットしてください

---

実行: チャット入力で `/commit` を選択してください。
