# 画面設計

## 画面一覧

### 公開（認証不要）

| パス | 画面名 | 説明 |
|---|---|---|
| `/` | ランディングページ | サービス紹介、サインアップ/ログインへの導線 |
| `/sign-up` | アカウント登録 | メール + パスワード入力。完了時に組織を自動作成 |
| `/sign-in` | ログイン | メール + パスワード |
| `/events/[eventId]` | イベント公開ページ | イベント詳細 + 申込フォーム。SNSシェアや直リンク用 |
| `/embed/[eventId]` | iframeウィジェット | 外部サイトに埋め込まれる申込フォーム |
| `/cancel` | キャンセル確認ページ | `?token=xxx` でアクセス。「キャンセルしますか？」確認UI |

### ダッシュボード（要認証）

| パス | 画面名 | 説明 |
|---|---|---|
| `/dashboard` | イベント一覧 | 自組織のイベント一覧。ステータス別フィルタ |
| `/dashboard/events/new` | イベント作成 | |
| `/dashboard/events/[id]` | イベント編集 | 埋め込みコード取得もここから |
| `/dashboard/events/[id]/registrations` | 申込者一覧 | CSVエクスポートボタンあり |
| `/dashboard/settings` | 組織設定 | 組織名変更、メンバー招待・管理 |

## 主要フロー

### 主催者：はじめて使うとき

```
/sign-up
  → メール + パスワード入力
  → 組織を自動作成（組織名 = ユーザー名、あとで変更可）
  → /dashboard へリダイレクト
  → イベント作成 → 埋め込みコード取得 → 自社サイトに貼る
```

### 主催者：日常運用

```
/dashboard
  → イベント一覧確認
  → /dashboard/events/[id]/registrations で申込者確認
  → CSVエクスポート or 個別キャンセル
```

### 申込者：申込

```
外部サイト（iframeウィジェット）
  → 名前 + メールアドレス入力 → 送信
  → redirectUrl 設定あり  : 指定URLへリダイレクト
  → redirectUrl 設定なし  : 完了ダイアログをその場で表示
```

### 申込者：キャンセル（P1）

```
確認メール受信
  → キャンセルリンクをクリック（GET /cancel?token=xxx）
  → キャンセル確認画面
  → 「キャンセルする」ボタン押下（POST /api/registrations/cancel）
  → キャンセル完了メッセージ表示
```

---

## 備考

- サインアップ時の組織作成は自動（TimeRex と同方式）。組織名はユーザー名で初期設定され、`/dashboard/settings` でいつでも変更可能
- `/embed/[eventId]` は最小限のUIで外部サイトに馴染むデザインを優先。レスポンシブ対応
- キャンセルフローは P1（メール通知実装時に同時対応）
